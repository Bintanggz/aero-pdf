🚀 [PROJECT SHOWCASE] AeroPDF — Client-Side Document Studio

Sering ragu saat harus upload file PDF kantor atau dokumen sensitif ke website PDF converter gratisan? Kebanyakan platform online mengunggah file Anda ke server cloud pihak ketiga yang berisiko dari sisi privasi dan keamanan data.

Untuk menjawab masalah ini, saya membangun **AeroPDF**: web application utilitas PDF modern yang bekerja **100% di browser pengguna**.

✨ Kenapa AeroPDF Berbeda?
1. 🔒 100% Privat & Aman: Seluruh dokumen diproses langsung di memori perangkat browser tanpa pernah diunggah ke server mana pun (Zero Server Upload).
2. ⚡ Kecepatan Kilat: Menggunakan engine WebAssembly & PDF-Lib untuk kompresi, rotasi, dan penggabungan dokumen instan tanpa latensi upload/download jaringan.
3. 💸 Zero Server Maintenance Cost: Dapat dihosting secara statis (Vercel Edge) tanpa biaya server bulanan.
4. 🎨 Minimalist Document Workspace: Antarmuka clean, intuitif, mendukung drag-and-drop, validasi file real-time, dan auto memory cleanup untuk performa stabil.

🛠️ Fitur yang Tersedia:
• Gabungkan PDF (Merge multi-file)
• Pisahkan PDF (Split & extract custom range)
• Kompres PDF (Smart slider compression)
• Gambar ke PDF (Multi-format convert)
• Putar Orientasi Halaman (Rotate 90°/180°/270°)
• PDF ke Gambar (High-res PNG export)
• Pratinjau Dokumen (Built-in Viewer)

💻 Tech Stack:
• Frontend: React 18, TypeScript, Vite
• Styling: Tailwind CSS & Lucide Icons
• Document Engine: PDF-Lib & WebAssembly
• Deployment: Vercel (Live Demo)
